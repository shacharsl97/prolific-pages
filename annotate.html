item 1 of 8 Guidelines

Revise the marked statements

The source is on the left and never changes. On the right is a summary of it with the unfaithful statements already marked. For each one: say which question it and the source both answer, then replace it with the source’s answer — or delete it if the source has no answer to give.

Please do not use any LLMs. We are studying how people write faithful minimal revisions, so we need your own work.
