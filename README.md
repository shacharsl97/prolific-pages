Worker-facing pages for a Prolific study on minimal revision of summaries.

This repository is public because GitHub Pages requires it. It therefore holds
**only** pages that are meant to be read by participants. No item pool, no
reference revisions, no analysis, no notes: those live in the private project
repository and must never be copied here.

- `demo.html` — the training stage. Six practice items with worked solutions,
  which participants are meant to see. It records no answers.
